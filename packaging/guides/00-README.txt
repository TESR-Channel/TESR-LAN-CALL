TESR LAN Call  เวอร์ชัน __VERSION__
โปรแกรมโทรวิดีโอภายในองค์กร ผ่าน Wi-Fi / LAN ของบริษัท
=====================================================

เลือกโฟลเดอร์ตามอุปกรณ์ของคุณ แล้วเปิดไฟล์ "วิธีติดตั้ง" ในโฟลเดอร์นั้น

  For-Windows        คอม Windows 10 / 11
  For-Mac            MacBook, iMac, Mac mini (ทั้งชิป M และ Intel)
  For-Linux          คอม Ubuntu / Debian
  For-Raspberry-Pi   Raspberry Pi 4 / 5
  For-iPad-Mobile    iPad, iPhone, มือถือ Android (ไม่ต้องติดตั้ง)
  For-Robot          ตั้งค่าเครื่องบนหุ่นยนต์ Kuro-X หรือจอหน้างาน
  Resources          ไอคอนและโลโก้ทุกขนาด
  Source-Code        สำหรับทีมพัฒนา (แก้โปรแกรม / สร้างตัวติดตั้งใหม่)


สิ่งที่ต้องรู้ก่อนใช้
----------------
1. ทุกเครื่องต้องต่อ Wi-Fi หรือสาย LAN วงเดียวกัน ไม่ต้องใช้อินเทอร์เน็ต
2. ติดตั้งครั้งเดียว โปรแกรมจะเปิดเองทุกครั้งที่เปิดเครื่อง และทำงานอยู่เบื้องหลัง
   เมื่อมีคนโทรมา หน้าต่างจะเด้งขึ้นมาพร้อมเสียงเรียก
3. ปิดหน้าต่างได้ตามปกติ ยังรับสายได้อยู่ ถ้าต้องการปิดจริงให้กดปุ่ม "ปิดโปรแกรม"
4. มือถือและ iPad ใช้งานผ่านคอมเครื่องใดก็ได้ที่ลงโปรแกรมไว้ ดูในโฟลเดอร์ For-iPad-Mobile


วิธีโทร
------
1. เปิดโปรแกรม จะเห็นรายชื่อเครื่องที่ออนไลน์อยู่ในบริษัท
2. กด "โทร" ที่ชื่อปลายทาง
3. ปลายทางกด "รับสาย" (เครื่องที่เปิดโหมดหุ่นยนต์จะรับเองทันที)
4. ระหว่างคุย ปิด/เปิดไมค์ กล้อง สลับกล้อง แชร์หน้าจอได้ กด "วางสาย" เมื่อจบ
5. สายที่ไม่ได้รับจะอยู่ใน "ประวัติการโทร" พร้อมปุ่ม "โทรกลับ"


ติดปัญหา
--------
- ไม่เห็นเครื่องอื่น: เช็กว่าอยู่ Wi-Fi วงเดียวกัน (Wi-Fi สำหรับแขกมักบล็อกการคุยกันระหว่างเครื่อง)
  ถ้ายังไม่เห็น ให้กด "เพิ่มด้วย IP" แล้วใส่ IP ของเครื่องปลายทาง
- ไฟร์วอลล์ต้องเปิดพอร์ต TCP 47800, TCP 47843 และ UDP 47801
  (ตัวติดตั้ง Windows และ Linux เปิดให้อัตโนมัติ)
- ไฟล์บันทึกการทำงาน (log) อยู่ที่โฟลเดอร์ .tesr_lan_call ในโฟลเดอร์ผู้ใช้
