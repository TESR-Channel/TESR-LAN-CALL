TESR LAN Call สำหรับ Linux (Ubuntu 20.04 ขึ้นไป / Debian 11 ขึ้นไป)
====================================================================

ติดตั้ง
------
วิธีที่ 1 (ง่ายสุด): ดับเบิลคลิกไฟล์ .deb แล้วกด Install

วิธีที่ 2: เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์
    sudo apt install ./tesr-lan-call___VERSION___amd64.deb

เสร็จแล้วจะมีไอคอน TESR LAN Call บน Desktop และในเมนูแอป
ถ้าไอคอนบน Desktop ขึ้นว่าเปิดไม่ได้ ให้คลิกขวา > "Allow Launching"

ครั้งแรกกด "อนุญาต" กล้อง ไมค์ และการแจ้งเตือน


แนะนำ
-----
ติดตั้ง Chromium หรือ Google Chrome เพื่อให้เปิดเป็นหน้าต่างแอป
    sudo apt install chromium-browser      (Ubuntu)
    sudo apt install chromium              (Debian)


ใช้งาน
-----
- เปิดจากไอคอน หรือพิมพ์  tesr-lan-call
- ปิดหน้าต่างได้ โปรแกรมยังทำงานอยู่ มีสายเข้าจะเด้งขึ้นมาเอง
- ถ้าใช้ ufw ตัวติดตั้งเปิดพอร์ตให้แล้ว (TCP 47800, 47843 และ UDP 47801)


ถอนการติดตั้ง
-----------
    sudo apt remove tesr-lan-call
