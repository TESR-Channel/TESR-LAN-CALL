TESR LAN Call สำหรับหุ่นยนต์ Kuro-X และจอหน้างาน
==================================================

โหมดหุ่นยนต์ทำอะไร
-----------------
- เปิดเต็มจอทันทีตอนเปิดเครื่อง
- ทุกสายที่โทรเข้ามา จะรับเองภายใน 1 วินาที ไม่ต้องมีคนกด
- อนุญาตกล้องและไมค์ให้อัตโนมัติ
ผู้ควบคุมขับหุ่นด้วยโปรแกรมเดิมตามปกติ พอถึงเป้าหมายก็กดโทรหา "Kuro-X" ได้ทันที
คนหน้าหุ่นจะเห็นหน้าผู้ควบคุมบนจอหุ่น และคุยกันได้เลย


ตั้งค่า (เลือกตามระบบของคอมบนหุ่น)
---------------------------------
Windows:
  ติดตั้งจาก For-Windows แล้วในหน้าเลือกส่วนประกอบ ติ๊ก "โหมดหุ่นยนต์ / จอแสดงผล"

Linux / Raspberry Pi:
  ติดตั้งจาก For-Linux หรือ For-Raspberry-Pi แล้วเปิด Terminal พิมพ์ครั้งเดียว
      tesr-lan-call --robot

ทุกระบบ (รวม Mac):
  เปิดโปรแกรม > กล่อง "เครื่องนี้" > ติ๊ก "โหมดหุ่นยนต์ / จอแสดงผล"
  แล้วปิดและเปิดโปรแกรมใหม่หนึ่งครั้ง

ตั้งชื่อเครื่องให้ชัด เช่น "Kuro-X 01" จะได้หาเจอง่ายในรายชื่อ


ข้อแนะนำ
-------
- ต้องมีกล้อง ไมค์ และลำโพงบนหุ่น แนะนำไมค์แบบตัดเสียงสะท้อน (speakerphone)
- หุ่นวิ่งไกล router สัญญาณจะตก ควรมี access point ครอบคลุมเส้นทางที่หุ่นวิ่ง
- แนะนำให้ฝ่าย IT ตั้ง IP ของหุ่นให้ตายตัว
- ออกจากโหมดเต็มจอ: กด Alt+F4 (Windows/Linux) หรือ Cmd+Q (Mac)
- ปิดโหมดหุ่นยนต์: เอาติ๊ก "โหมดหุ่นยนต์ / จอแสดงผล" ออกในหน้าโปรแกรม
