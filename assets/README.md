# assets

ใส่โลโก้จริงของ TESR ที่นี่ได้เลย (อัปโหลดผ่านหน้าเว็บ GitHub: Add file > Upload files)

| ไฟล์ | รายละเอียด |
|---|---|
| `icon-1024.png` | ไอคอนแอป สี่เหลี่ยมจัตุรัส 1024 x 1024 px |
| `logo.png` | โลโก้แนวนอน พื้นโปร่งใส อ่านออกบนพื้นดำ (สูง 120 px ขึ้นไป) |

ถ้ายังไม่มีสองไฟล์นี้ ระบบ build จะสร้างโลโก้ชั่วคราวสี CI (ดำ / แดงเข้ม / ทอง) ให้อัตโนมัติ
ไอคอน Windows (.ico), Mac (.icns), Linux และ iPad ทุกขนาดจะถูกสร้างจาก `icon-1024.png` ตอน build
ฟอนต์ Chakra Petch และ IBM Plex Sans Thai (OFL) ดาวน์โหลดอัตโนมัติตอน build
